## 👋 Привет

Я backend-инженер: Go, C#, Python и немного TypeScript. Люблю распределённые
системы, аккуратные контракты и автоматизацию — если что-то делается руками
дважды, это повод написать сервис.

- 🔭 Сейчас развиваю [job-agent](https://github.com/Darkon13/job-agent) —
  локальный сервис автоматизации поиска работы: адаптеры платформ, durable
  задачи, browser-автоматизация и dashboard.
- 🛠️ Верю в конфиг вместо кликов: декларативные системы, идемпотентность,
  наблюдаемость и восстановление после сбоев.
- 🧪 Пишу тесты до того, как поверю в код: race detector, contract-тесты,
  живые проверки.
- ⌨️ Neovim, Linux, терминал — не потому что модно, а потому что быстрее.

- **CI** — `go test -race`, `vet` и runtime smoke на каждый PR.
- **CodeQL** — анализ Go и TypeScript на уязвимости.
- **Dependabot** — обновления Go, npm и GitHub Actions.
- **PR-бот** — лейблы и один обновляемый комментарий со статусом проверок.
- **Защита main** — аппрувы, code owners и секрет-скан с push protection.
